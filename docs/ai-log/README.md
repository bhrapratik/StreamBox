# AI work log

Every AI-assisted change gets one entry here (written with `/ai-log` before committing),
and one row in [metrics.md](metrics.md).

Why: anyone can see what the agent did, what checked it, what went wrong and what the
human decided — and the metrics show whether the workflow is actually getting better.

Commits for AI-assisted work end with:
    AI-Log: docs/ai-log/<file>.md
